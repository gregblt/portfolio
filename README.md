# Portfolio — Grégory Bliault

Site personnel statique : présentation, projets à la une, parcours en logos avec panneau de détail redimensionnable, publications.

HTML, CSS et JavaScript, sans étape de build ni dépendance (seules les polices viennent de Google Fonts).

## Structure

- `index.html` : la page entière (styles et scripts inclus)
- `photo.jpg` : portrait de la section d'accueil
- `logos/` : logos du parcours et des projets (voir `logos/README.md`)

## Voir le site en local

Ouvrir `index.html` dans un navigateur, ou lancer `python3 -m http.server` puis aller sur http://localhost:8000.

## Mise en ligne

Le dossier est déjà publiable tel quel (GitHub Pages, Netlify, Cloudflare Pages…).
